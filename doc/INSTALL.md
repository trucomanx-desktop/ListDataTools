# List Data Tools

A set of program to list data.


## Install from PYPI

The homepage in pipy is https://pypi.org/project/list_data_tools/

```bash
pip install --upgrade list_data_tools
```

Using:

```bash
ldt-files
```

## Install from source
Installing `ldt-files` program

```bash
git clone https://github.com/trucomanx-desktop/ListDataTools.git
cd ListDataTools
pip install -r requirements.txt
cd src
python -m build
pip install dist/list_data_tools-*.tar.gz
```
Using:

```bash
ldt-files
```

## Uninstall

```bash
pip uninstall list_data_tools
```
